Nothing private goes in the report. It only reads (nothing on the miner is changed), and it's plain text you can check before sending. What's left out:
  • Never read at all: the pool settings (pool address, wallet, worker and its password), the WiFi settings (network names and passwords) and the miner's pool list on port 4028.
  • Never written: the miner's password and the login token.
  • Taken out of everything that is read: the MAC address (shown as 00:11:22:33:44:55), IP addresses, web and pool addresses, e-mail addresses, and anything that looks like a wallet address or a token.
  • Removed: any setting named like user, password, wallet, worker, pool, url, ssid, host, ip, mac or serial, and any text that mentions a pool, a user, a wallet or the network.
  • From the miner's log (only if ticked): every line that mentions a pool, a user, a worker, a wallet, a login or the network is dropped whole. Untick "with the miner's log" to leave the log out entirely.

What stays: model and firmware, the clock and voltage plans, boards, chips, fans, temperatures, hashrate and error counts. The zip's README.txt lists the same, and summary.txt says how many log lines were dropped.

Everything on this page is per miner: pick the miner here. Fan curves are a shared list any miner can use; presets belong to the miner they were made for.

Presets

A preset is a clock, voltage and PV plus the fan curve to run them with. The tuner builds High, Middle, Low and Lowest power for each miner and tests every one with its own fan curve (tick Build presets on the Tuner page). Apply puts the clock on the miner and switches its auto fan to that curve.

New preset

Clocks you type in are not tested. A clock or voltage the chips can't run makes errors and can overheat the boards. Use the tuner to find safe settings; hand-set presets are marked not tested.

Fan curves

saved

The curve says how fast the fans run at each board temperature (the hottest board counts). Drag a point to move it, click an empty spot to add one, double-click a point to remove it (or select it and press Delete). Built-in curves can't be changed: press Copy to edit. The miner's own fan control slowly turns the fans back down, so the dashboard re-sends the curve's value every few seconds.

Safety temperature: at or above it the fans go to at least 90 % straight away, whatever the curve says. Re-send: how often the value is sent again; the miner's own control walks the fans back in between. Smoothing: follows the average of the last few readings so the fans don't hunt up and down; it never lets the fan lag more than 10 % behind a rise. Temperature control: the miner's own protection; leaving it on is safer.

Auto fan by miner

Each miner runs its own curve. Changes here take effect straight away. Offset adds or takes away fan % on top of the curve for that miner only (handy for a miner in a hotter spot).
