    Only the presets are tested again; the voltage curve isn't changed. Each preset starts at the curve's voltage for its clock. Warmer than the search's temperature, chips make more errors, so a preset may need one voltage step more, or one clock step less (that's the right answer for that temperature, not a wrong reading). Cooler is always safe, with louder fans. Only clocks the search mapped can be used: for others, run a new search.

    Setting to confirm

    Confirm only

    The time is split into rounds as long as one test (section 7). Each round is judged like a search test. A round that fails gets one retest; if the retest fails too, the setting is REJECTED.

    3

    Baseline

    Search and confirm
    —

    The baseline runs first so the tuner can learn every chip's normal error rate, and every test is compared with that (a faster clock is allowed proportionally more errors, since it does more work). It has to be a setting the miner runs steadily: a board reset during the baseline stops the run at once. Whatever you pick, if nothing is confirmed or the run stops early, the miner goes back to what it ran before the run, not to stock. Longer = a more accurate baseline (60 min is a good choice).

    4

    Clocks and voltages to map

    Search only

    The curve starts at Lowest MHz and works up one step at a time to Highest MHz, so it covers underclocking and overclocking in one run. At each clock it finds the lowest voltage that stays clean: the lowest clock starts at the baseline voltage; every higher clock starts at the voltage that was lowest one clock slower, plus one step if the clock before needed more. If that isn't clean it adds voltage a step at a time (up to Highest mV); then it lowers voltage a step at a time until it fails (down to Lowest mV; it stops after two failures in a row, or one at a voltage a slower clock already failed at). Every voltage is tested at its own clock: nothing is assumed from another clock. The curve ends at the first clock that isn't clean at any allowed voltage. The miner sets clocks in 12.5 MHz steps, so a 25 MHz step lands every test on a clock it really runs.

    Off: each clock only gets voltage added until it's clean, never lowered: a quicker, rougher curve.

    Runs the best setting once more at the end, by default for twice the test length, so the winner has the most time behind it. If it fails, the next-best passing setting is confirmed instead.

    Test length and safety

    All options

    Minutes per test: how long each setting is watched (plus 3 minutes to settle). Longer catches a slightly weak chip more reliably; bad settings still fail early. Sensitivity: how sure the tuner must be that a chip got worse before a test fails. Errors are random, and every chip is checked, so the limits are set so that a perfectly good setting fails by bad luck only about 1 test in 20 at 2.5 (the default). Lower is stricter (2.0: about 1 in 5, more false fails); higher is more forgiving (3.0: about 1 in 100, but a slightly weak setting can slip through). Abort: if any board reaches this temperature the run stops and the miner goes back to what it ran before the run.

    A weak or damaged chip makes far more errors than the rest no matter the clock or voltage. Judged like the others, its random ups and downs fail good settings and push the voltage up for every chip. With this on, a chip at least 8 times noisier than the typical chip during the baseline only fails a step when it gets clearly worse (1.5 times its own normal rate). The board totals are judged on the normal chips. The Run plan lists them.

    7

    Fans during the run

    All options

    Target: the temperature the hottest board is held at during the search (and for the High preset). 60 °C is a good start. Lowest fan: the fans never go below this, even when the boards are cool.

    8

    Presets

    Search only

    After the search, four presets are made for this miner and each is tested on its own: High (the best clock), Lowest power (the Lowest MHz from section 4), and Middle and Low spread evenly between them. Each uses the lowest clean voltage the curve measured at its clock. A preset that fails gets more voltage, then a lower clock, up to 3 tries. They appear on the Profiles page, where one click puts a preset and its fan curve on the miner.
